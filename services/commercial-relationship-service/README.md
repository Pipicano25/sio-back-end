# commercial-relationship-service

Microservicio FastAPI de SIO. Se despliega en su propio contenedor Docker
(ver `Dockerfile` una vez implementado) con su propia base de datos
independiente (ver `docs/service-map.md` en la raíz del repo).

Esta carpeta se llena a través del ciclo `/speckit-specify` →
`/speckit-plan` → `/speckit-tasks` → `/speckit-implement` — no se
escribe código a mano aquí antes de pasar por ese ciclo.
