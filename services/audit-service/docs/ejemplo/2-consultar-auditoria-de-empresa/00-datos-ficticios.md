# Datos del ejercicio 2 (ficticios)

No existe una fuente del sistema anterior para eventos de auditoría: todos los datos son **ficticios** y sus identificadores son fijos para que la documentación sea estable.

| Dato | Valor | Interpretación |
| --- | --- | --- |
| Empresa | `a11d0000-0000-4000-8000-000000000001` | Todos los usuarios de prueba son miembros (Operational Context simulado). |
| Otra empresa | `a11d0000-0000-4000-8000-000000000099` | Ningún usuario de prueba es miembro. |
| Precio de lista | `b22e0000-0000-4000-8000-000000000010` | Entidad con historial: creación, cambio y un intento fallido. |
